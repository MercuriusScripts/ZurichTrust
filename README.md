# ZurichTrust

**Secure, anonymous banking application hosted on the Tor network.**

Built for financial privacy and accessibility. ZurichTrust operates exclusively as a .onion hidden service, ensuring complete anonymity for its users.

---

## Features

- 🔐 **Encrypted Accounts** – All data is encrypted at rest
- 💰 **Balance Management** – Check balances, deposit, withdraw
- 📜 **Transaction History** – Full audit trail of all activity
- 🔄 **Peer-to-Peer Transfers** – Send funds between accounts
- 🧅 **Tor Only** – No clearnet exposure, accessible only via .onion
